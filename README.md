# คลังเอกสารการเรียน — โรงเรียนแผนที่ กรมแผนที่ทหาร

เว็บไซต์สำหรับให้นักเรียนแผนที่ ชั้นปีที่ 1 และชั้นปีที่ 2 เลือกรายวิชาเพื่อดาวน์โหลดเอกสารประกอบการเรียน
สร้างด้วย **Next.js 14 (App Router)** + **TypeScript** + **Tailwind CSS**

## วิธีติดตั้งและรัน (ต้องมี Node.js 18.17 ขึ้นไป)

```bash
npm install
```

**ตั้งค่ารหัสผ่านก่อนรันครั้งแรก** (ดูหัวข้อ "ระบบรหัสผ่านแยกตามชั้นปี" ด้านล่าง) ไม่งั้นหน้าปี 1/ปี 2 และไฟล์เอกสารจะเข้าไม่ได้

```bash
npm run dev
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## ระบบรหัสผ่านแยกตามชั้นปี

เว็บนี้กันรหัสผ่านแยกกันระหว่างชั้นปีที่ 1 และชั้นปีที่ 2 — นักเรียนต้องกรอกรหัสผ่านของ
ชั้นปีตนเองก่อนจึงจะดูรายวิชา **และดาวน์โหลดไฟล์เอกสารได้** (ระบบกันทั้งหน้าเว็บและลิงก์ไฟล์
โดยตรง ไม่ใช่กันแค่หน้าเว็บ) หน้าแรกสำหรับเลือกชั้นปียังเข้าได้โดยไม่ต้องใส่รหัสผ่าน

### วิธีตั้งค่า

1. คัดลอกไฟล์ `.env.local.example` เป็น `.env.local`

   ```bash
   cp .env.local.example .env.local
   ```

2. เปิด `.env.local` แล้วใส่ค่า 3 ตัว:

   ```
   AUTH_SECRET=<ข้อความสุ่มยาว ๆ ใช้เป็นกุญแจเซ็น cookie>
   YEAR1_PASSWORD=<รหัสผ่านของชั้นปีที่ 1>
   YEAR2_PASSWORD=<รหัสผ่านของชั้นปีที่ 2>
   ```

   สร้างค่า `AUTH_SECRET` แบบสุ่มได้ด้วยคำสั่ง (macOS/Linux/Git Bash):

   ```bash
   openssl rand -hex 32
   ```

   หรือถ้าไม่มี `openssl` จะพิมพ์ข้อความยาว ๆ สุ่มเองก็ได้ (อย่างน้อย ๆ 32 ตัวอักษร)

3. รีสตาร์ต `npm run dev` ใหม่ (Next.js จะโหลดค่าจาก `.env.local` ตอนเริ่มรันเท่านั้น)

**ห้าม commit ไฟล์ `.env.local` ขึ้น git** (ตั้งค่าไว้ใน `.gitignore` ให้แล้ว) ส่วนเวลานำขึ้น
เซิร์ฟเวอร์จริง/Vercel ให้ไปตั้งค่า Environment Variables 3 ตัวนี้ในระบบ deploy แทน

### กลไกการทำงาน (ไม่มีฐานข้อมูล)

- ผู้ใช้กรอกรหัสผ่านที่หน้า `/login` → ระบบเทียบกับ `YEAR1_PASSWORD`/`YEAR2_PASSWORD` ใน `.env.local`
- ถ้าถูกต้อง ระบบจะออก cookie (`httpOnly`) ที่เซ็นชื่อด้วย `AUTH_SECRET` แบบ HMAC-SHA256
  อายุ 30 วัน แยกคุกกี้ของปี 1 (`auth_year1`) และปี 2 (`auth_year2`) ออกจากกัน
- `middleware.ts` จะตรวจคุกกี้นี้ทุกครั้งที่เข้า `/year/1`, `/year/2` หรือไฟล์ใต้ `/files/1/...`, `/files/2/...`
  ถ้าไม่มีคุกกี้ที่ถูกต้อง จะเด้งไปหน้า `/login` ให้กรอกรหัสผ่านใหม่
- มีปุ่ม "ออกจากระบบ" ในหน้ารายวิชา/หน้าไฟล์ เพื่อล้างคุกกี้และออกจากระบบ

สำหรับการใช้งานจริง (deploy) ให้รัน:

```bash
npm run build
npm run start
```

หรือจะนำโปรเจกต์นี้ขึ้น Vercel / เซิร์ฟเวอร์ของโรงเรียนก็ได้เช่นกัน

## วิธีเพิ่มไฟล์เอกสารให้นักเรียนดาวน์โหลด (ไม่ต้องแก้โค้ด)

ไฟล์ทั้งหมดถูกเก็บไว้ในโฟลเดอร์ `public/files/[ชั้นปี]/[รหัสวิชา]/`
เพียงนำไฟล์ (PDF, PPTX, DOCX, XLSX, ZIP ฯลฯ) ไปวางในโฟลเดอร์ที่ตรงกับวิชานั้น ระบบจะแสดงรายการ
และให้ดาวน์โหลดโดยอัตโนมัติ ไม่ต้องรีสตาร์ทเซิร์ฟเวอร์หรือแก้โค้ดใด ๆ

โครงสร้างโฟลเดอร์ปัจจุบัน:

```
public/files/
  1/                              ← ชั้นปีที่ 1
    calculus1/                    ← แคลคูลัส 1
    strength-of-materials/        ← ความแข็งแรงวัสดุ
    engineering-mechanics/        ← กลศาสตร์วิศวกรรม
    math-stats/                   ← คณิตศาสตร์และสถิติ
  2/                              ← ชั้นปีที่ 2
    calculus1/
    strength-of-materials/
    engineering-mechanics/
    math-stats/
```

ตัวอย่าง: หากต้องการเพิ่มเอกสาร `บทที่1-ลิมิต.pdf` ให้วิชาแคลคูลัส 1 ของชั้นปีที่ 1
ให้นำไฟล์ไปวางที่ `public/files/1/calculus1/บทที่1-ลิมิต.pdf`

## วิธีเพิ่ม/แก้ไข/ลบรายวิชา

แก้ไขได้ที่ไฟล์ `lib/subjects.ts` โดยแก้ไข array `baseSubjects` (หรือแยกรายวิชาของปี 1
และปี 2 ให้ต่างกันได้ในตัวแปร `years`) แต่ละวิชาประกอบด้วย:

- `slug` — รหัสวิชา (ใช้เป็นชื่อโฟลเดอร์ใน `public/files/...` ด้วย ห้ามมีช่องว่าง)
- `name` / `nameEn` — ชื่อวิชาภาษาไทย/อังกฤษ
- `sheet` / `grid` — ป้ายกำกับสไตล์ระวางแผนที่ (ตกแต่งเท่านั้น แก้ไขได้อิสระ)
- `description` — คำอธิบายสั้น ๆ ของวิชา

หากเพิ่มวิชาใหม่ อย่าลืมสร้างโฟลเดอร์คู่กันใน `public/files/[ปี]/[slug]/` ด้วย

## โครงสร้างโปรเจกต์

```
app/
  layout.tsx                    ← โครงหน้าเว็บหลัก, ฟอนต์
  page.tsx                      ← หน้าแรก: เลือกชั้นปี (ไม่ต้องใส่รหัสผ่าน)
  login/page.tsx                ← หน้ากรอกรหัสผ่าน
  year/[year]/page.tsx          ← หน้ารายวิชาของแต่ละชั้นปี (ต้องล็อกอิน)
  year/[year]/[subject]/page.tsx← หน้ารายการไฟล์ของแต่ละวิชา (ต้องล็อกอิน)
  api/login/route.ts            ← ตรวจรหัสผ่าน + ออกคุกกี้
  api/logout/route.ts           ← ล้างคุกกี้ / ออกจากระบบ
  not-found.tsx                 ← หน้า 404
middleware.ts                   ← จุดตรวจรหัสผ่านก่อนเข้าหน้า/ไฟล์ที่ป้องกันไว้
components/                     ← ส่วนประกอบ UI ที่ใช้ซ้ำ (รวม LoginForm, LogoutButton)
lib/
  subjects.ts                   ← ข้อมูลรายวิชา (แก้ไขได้ตามต้องการ)
  files.ts                      ← ฟังก์ชันอ่านรายชื่อไฟล์จาก public/files
  auth.ts                       ← ฟังก์ชันสร้าง/ตรวจ token เข้าสู่ระบบ
public/files/                   ← ที่เก็บไฟล์เอกสารจริง (แอดมินวางไฟล์ที่นี่)
.env.local.example              ← แม่แบบไฟล์ตั้งค่ารหัสผ่าน (คัดลอกเป็น .env.local)
```

## หมายเหตุ

- ระบบนี้ไม่มีฐานข้อมูล ไม่มีระบบล็อกอิน เหมาะสำหรับใช้งานภายในที่เข้าถึงเอกสารแบบเปิด
  หากต้องการจำกัดสิทธิ์การเข้าถึง (เช่น ต้องล็อกอินก่อนดาวน์โหลด) สามารถต่อยอดเพิ่มระบบ auth ภายหลังได้
- ชื่อไฟล์ที่วางใน `public/files/...` จะแสดงเป็นชื่อที่นักเรียนเห็นตรง ๆ ควรตั้งชื่อไฟล์ให้สื่อความหมาย เช่น
  `บทที่1-ลิมิตและความต่อเนื่อง.pdf`
